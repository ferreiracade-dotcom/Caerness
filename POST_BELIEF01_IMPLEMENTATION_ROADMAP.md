## Immediate next task — DEC-01 information-bounded decision rewrite

Replace the centralized generic decision/action architecture with:

```text
actor belief / information envelope
→ sensors
→ domain behavior providers
→ concrete candidate actions tied to real world objects
→ feasibility
→ utility / proclivity
→ weighted selection
→ domain-owned execution
```

### Hard rules

- Decision code receives actor-accessible information, not omniscient truth.
- Concrete candidates refer to actual people, contracts, enterprises, routes, claims, rackets, offices, injuries, etc.
- Domain owners execute mutations; the decision layer does not own everybody else's state.
- Use weighted/softmax-like choice among plausible options rather than deterministic global argmax.
- Preserve deterministic actor RNG for replayability/testing.
- Player actor remains excluded from autonomous strategic choice.
- Competence changes what evidence is noticed/interpreted and which actions are feasible, not what hidden facts exist.
- Presence gates direct/spontaneous encounter where actual co-presence matters; it is not a random tax on arrangeable city-level services or correspondence.

## DEC-01 initial vertical slice

Use the underworld as the first rich provider because REL/PRES/BELIEF/ECON already give it useful primitives.

Candidates should be concrete, for example:

- respond to a specific protection-account poaching attempt;
- collect or renegotiate a specific tribute/share obligation;
- retaliate for a specific grievance/evidence trail;
- seek a truce with a specific organization/person;
- discipline/promote/delegate a specific crew member;
- expand a real racket into a real eligible account/territory;
- invest treasury or personal estate funds through explicit money flows;
- investigate a claim/rumour where the actor lacks sufficient confidence.

Do not create a hidden universal criminal promotion ladder or gang→Mafia-family evolution ladder.
