## Immediate next slice — GROWTH-01 regional growth / state capacity

The next slice should stop treating a “backwater count becomes prosperous” outcome as a direct prosperity meter increase. It should prove that a region can change because real systems accumulate and constrain one another.

### Target causal chain

Use one deliberately modest county/count-sized polity or district and run a bounded multi-year experiment through real owners:

```text
population / households
+ land / food base
+ roads and route reliability
+ market access
+ local enterprises / workshops / merchants
+ security
+ administration / offices
+ tax/revenue capacity
+ projects / infrastructure
+ migration
→ changing settlement and state capacity
```

No `development_score += 10` should substitute for those mechanisms.

### Required regional objects / ownership

Before the experiment, identify or add minimal shared owners for:

- local jurisdiction / polity relationship;
- population and household base;
- taxable economic base;
- ordinary enterprises and employment;
- market connectivity and route access;
- food/agricultural support at the resolution actually needed;
- local security pressure;
- administrative staff/offices/capacity;
- public revenue and expenditure flows;
- infrastructure/project state;
- migration pressure and actual household movement;
- information available to the count/administrator.

Prefer existing objects. Add a new owner only where current state has no authoritative home.

### State capacity, not magic governance

A ruler’s intention such as:

> “Make merchants want to use this county without bankrupting us.”

must translate through competent administration into bounded proposals such as:

- repair a specific road/bridge;
- fund a market or warehouse project;
- alter an actual toll/tax rule if legally available;
- hire/appoint staff;
- improve security on a specific route;
- negotiate with a merchant house;
- borrow or defer a project when cash is insufficient.

The ruler should not directly set prosperity, migration, prices or business creation.

### Revenue conservation

GROWTH-01 should add/strengthen a real public-fiscal owner if the current polity subsystem lacks one:

```text
tax / toll / rent / fee source
→ public treasury
→ payroll / infrastructure / security / debt service
```

Projects cannot complete merely because political intent exists. Money, material, labor, route access and time must matter at the selected resolution.

### Migration and business response

Households and enterprises should react to causes they can actually experience:

- employment/opportunity;
- security;
- housing/capacity;
- market access;
- tax/toll burden;
- food stress;
- kin/institutional ties.

Do not script population growth simply because the ruler chose “develop county.”

### Cross-system reuse

GROWTH-01 should reuse:

- PRES-01 for presence/contact;
- BELIEF/Competence for administrative information;
- DEC-01 for concrete ruler/official/merchant choices;
- MERCHANT-01 for commerce and cargo;
- CRAFT-01 for local productive capacity;
- ecology/routes for connectivity;
- households for migration/demography;
- politics/law for authority;
- EVENTS-01 where a strategic public owner benefits from replay/audit.

### Acceptance experiment

Use a 10–15 year bounded county-growth experiment, but **not** the final world ten-year simulation.

The experiment should begin from a genuine backwater condition and test whether a plausible sequence can emerge:

1. weak market connectivity and limited treasury;
2. ruler/official has incomplete information and finite authority;
3. a specific infrastructure/security/commercial intervention is selected;
4. real funds/material/labor are committed;
5. route/market conditions improve only if the project actually succeeds;
6. merchants/workshops respond through their existing systems;
7. employment/household income or business activity changes;
8. migration may respond;
9. tax/revenue base changes from real activity;
10. the polity can reinvest, overextend, stagnate or regress depending on causal conditions.

Run multiple seeds/initial conditions. Growth is not the required outcome; **causal responsiveness** is.

A bad harvest, insecurity spike, failed project, excessive borrowing or merchant withdrawal must be capable of stalling/reversing the trajectory.

## Architecture rule

> Vertical slices must deepen one world. A county is not a city-builder minigame, a merchant is not a trade minigame, and a workshop is not a crafting minigame. They are people and institutions acting through the same goods, money, routes, property, information and authority.
